Руководство пользователя

Для того чтобы сгенерировать PnP (Pick and place) файл необходимо:

  1. Открыть вкладку "Генерация PnP"
  2. Открыть спецификацию в формате .xlsx
  3. Выбрать необходимые настроки (по умолчанию настройки подготовлены для стандартной спецификации)
    4. Если в конечном файле нужно отображение компонентов DNP, необходимо снять соответствующий чек-бокс.

  4. Открыть файл с координатами компонентов
    5. Поддерживаются два типа файлов:
    • Файл place (выгружается из Allegro PCB)
    • Файл PnP формата SiDeCo c расширением .xls
  5. Выбрать тип файла с координатами
  6. Выбрать тип выходного файла
    7. В данный момент поддерживается два типа выходного файла:
    • Стандартный файл
      • Соответствует последним утвержденным стандартам. Представляет собой текстовый файл.

    • Файл формата .xlsx с выделением типа монтажа цветом
      • Рекомендуется при заказе печатной платы в КНР.

  7. Выбрать необходимые настройки
    8. "Исключить HAND" - исключает из итогового файла ручной монтаж. "Исключить приставки" - исключает из итогового файла приставки типа "C-", "D-", "R-" и подобные.

  8. Нажать кнопку "Сгенерировать"
    9. Если чек-бокс "Открыть файл после генерации" активен, то отроется выходной файл, иначе он будет храниться в директории, где лежит файл спецификации.
